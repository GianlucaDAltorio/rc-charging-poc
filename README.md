# rc-charging-poc
Repository for Lab 2 in the Project I course.

This repository contains a research project exploring resistor-capacitor charging circuits.
How varying resistance and capacitance values shape a capacitor's charging curve, applied to a sample power-on-reset circuit for a microcontroller.

The `src/` folder contains the Python model used to generate the charging graphs, `figures/` holds the generated plots and schematics, and `report/` contains the LaTeX research document built in Overleaf. `main` holds the final rendition of the report.
